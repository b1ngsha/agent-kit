## Coding standards

Write or review React code: `CODING_STANDARDS.md` and
`docs/standards/code.md`.

## State

Add or change React state, an effect, or a mutation:
`docs/standards/state.md`.

## Routes

Change a route, search parameters, navigation, or route pending/error
behavior: `docs/standards/routing.md`.

## Tests

Write, review, or move a test: `docs/standards/testing.md`.

## Records

Change a behavior or contract, or add an ADR or a document under `docs/`:
`docs/standards/records.md`.

## Repo maintenance

Change a CI job or script, or add a runtime dependency:
`docs/standards/repo-maintenance.md`, the section for that change.

## Hooks

Install the repository's pre-commit hooks with `pnpm setup-hooks`.
