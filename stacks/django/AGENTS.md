## Coding standards

Write or review Python code: `CODING_STANDARDS.md`.

## Django code

Write Django views, serializers, services, models, tasks, or clients:
`docs/standards/code.md`.

## Tests

Write, review, or move a test: `docs/standards/testing.md`.

## Commands

Run `make fmt`, `make lint`, `make check`, `make test`, or `make run` through
uv. Run `make check-deploy` for the deployment-only Django audit.

## Hooks

After initializing Git, install the repository's pre-commit hooks with
`make setup-hooks`.
