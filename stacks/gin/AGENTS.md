## Coding standards

Write or review Go code: `CODING_STANDARDS.md`.

## Go tests

Write, review, or move a Go test: `docs/standards/testing.md`.

## Database

Change a table, column, seeded row, or migration: `docs/standards/database.md`.

## API contract

Change an OpenAPI operation, path, schema, field, or response:
`docs/standards/api-contract.md`.

## Records

Change a behavior or contract, or add an ADR or a document under `docs/`:
`docs/standards/records.md`.

## Repo maintenance

Change a CI job or script, or add a runtime dependency:
`docs/standards/repo-maintenance.md`, the section for that change.

## Hooks

Install the repository's pre-commit hooks with `make setup-hooks`.
